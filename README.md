# Task Tracker

## Problem Statement

People need a simple way to keep track of tasks they need to complete.

## Project Goal

The goal of this project is to create an Enterprise Java web application
that allows users to add, update, complete, and remove tasks.

## User Stories

### MVP User Stories

- As a user, I want to add a task so I can keep track of work that needs
  to be completed.
- As a user, I want to give a task a description so that I know what needs
  to be done.
- As a user, I want to add a due date to a task so that I know when it should
  be completed.
- As a user, I want to mark a task as complete so I can track my progress.
- As a user, I want to edit a task so I can correct or update its
  information.
- As a user, I want to delete a task that I no longer need.
- As a user, I want to view my active and completed tasks separately.

### Future User Stories

- As a user, I want to create an account and log in so my tasks are
  linked to my account.
- As a user, I want to access the application online after the app is deployed.

## Application Flow

1. The user opens the Task Tracker and views their active tasks.
2. The user can add a new task with a description and due date.
3. The new task appears in the active task list.
4. The user can edit, complete, or delete an active task.
5. Completed tasks move to the completed task list.
